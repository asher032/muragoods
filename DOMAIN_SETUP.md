## How to Get Your Clean Domain (2 minutes)

### Step 1: Go to Vercel Dashboard
1. Open **https://vercel.com/dashboard**
2. Log in with your GitHub account

### Step 2: Find Your Project
1. Click on the **muragoods-1xx6** project
2. Click **Settings** (top tab)

### Step 3: Rename the Project
1. In **General** → **Project Name**
2. Change `muragoods-1xx6` to `muragoods`
3. Click **Save**
4. Your new URL will be: **https://muragoods.vercel.app**

### Step 4: Update GitHub (if needed)
If Vercel can't rename due to a conflict:
1. Try `muragoods-app` → https://muragoods-app.vercel.app
2. Or `muragoods-shop` → https://muragoods-shop.vercel.app

## Free Custom Domain Options (Optional)

### Option A: Free .me Domain (Students Only)
If you have a **.edu email**:
1. Go to **https://education.github.com/pack**
2. Sign up for the GitHub Student Developer Pack
3. Claim your free **.me domain** from Namecheap
4. In Vercel Dashboard → Your Project → Settings → Domains
5. Add your `.me` domain
6. Update DNS as shown by Vercel

### Option B: Free Subdomains
- **is-a.dev** — Free `.is-a.dev` subdomain (requires GitHub PR)
- **js.org** — Free `.js.org` subdomain (for JS projects)
- **pp.ua** — Free `.pp.ua` subdomain

### Option C: Affordable Custom Domain
- **Porkbun** — .com domains ~$8/year
- **Cloudflare Registrar** — .com at cost (~$8/year)
- **Namecheap** — First year .com ~$6
